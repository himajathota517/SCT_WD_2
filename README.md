# Stopwatch Web Application

## SkillCraft Technology — Web Development Internship

**Task 02 | Stopwatch Web Application**

---

## Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship**.

The objective of Task 02 is to design and develop an **interactive, responsive, and user-friendly stopwatch web application** that enables users to accurately measure and record time intervals.

The application provides essential stopwatch functionality, including starting, pausing, resetting, and recording lap times. It is designed with a clean and intuitive interface to provide a smooth user experience.

---

## Task Objective

The primary objective of this task is to create a functional stopwatch application that allows users to:

- Start the stopwatch.
- Pause the stopwatch.
- Reset the elapsed time.
- Record individual lap times.
- Display recorded lap intervals clearly.
- Accurately measure elapsed time.
- Interact with the application through a simple and responsive interface.

---

## Key Features

### Stopwatch Controls

Provides essential controls to manage the stopwatch:

- **Start** — Begins time measurement.
- **Pause** — Temporarily stops the stopwatch.
- **Reset** — Resets the stopwatch to its initial state.

### Lap Time Tracking

Users can record multiple lap intervals while the stopwatch is running. Each recorded lap is displayed separately for easy reference.

### Real-Time Display

The elapsed time is updated dynamically, allowing users to monitor the stopwatch in real time.

### Responsive Interface

The application is designed to provide a consistent and accessible experience across different screen sizes, including desktop, tablet, and mobile devices.

### User-Friendly Design

The interface focuses on simplicity, clarity, and ease of use, allowing users to operate the stopwatch without unnecessary complexity.
